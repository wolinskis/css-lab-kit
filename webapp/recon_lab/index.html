🗂️ Recon Lab — Nested Directory Discovery

Goal: four admin-credential artifacts are hidden in a nested directory tree, one per level. Every directory name is a common word, so a small wordlist finds them — you just have to recurse.

  • Level 1 (easy) — a plaintext credential.
  • Level 2 (medium) — a Base64 login (decode it).
  • Level 3 (hard) — a password hash plus an ops-notes file with cracking tips.
  • Level 5 (expert) — a salted hash, deeper still.

Recommended list (small, already on Kali): /usr/share/wordlists/dirb/common.txt

# recursive (feroxbuster) — --add-slash makes it descend 200-dirs; link-extraction grabs the files:
feroxbuster -u http://localhost:8000/recon_lab/ \
  -w /usr/share/wordlists/dirb/common.txt --add-slash -C 404 -d 5

# or ffuf, one level at a time (append each dir you find; the page links its artifact):
ffuf -ic -u http://localhost:8000/recon_lab/FUZZ -w /usr/share/wordlists/dirb/common.txt -mc 200
ffuf -ic -u http://localhost:8000/recon_lab/backup/FUZZ -w /usr/share/wordlists/dirb/common.txt -mc 200

Each level page links its own artifact — the skill being practised is discovering the directories.
