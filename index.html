File-artifact labs — offline · forensics / PKI

Run ./build_all.sh to materialise the artifacts (nothing sensitive is committed). Here the "flag" is the recovered value — the password you crack, the key you find, the number you prove.

  • keys/ — ed25519, RSA, and a passphrase-protected encrypted_rsa.
