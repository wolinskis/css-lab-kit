🔐 Certificates & PKIoffline · openssl
🏁 Lab KitREADMESolution

Inspect a flawed certificate, validate a trust chain, and check revocation — all offline with openssl against the files below. Four escalating levels. Full answers in solution.md.

📦 Download the whole lab: certificates_lab.tar.gz · certificates_lab.zip — one file, includes all certs + README + solution
Files: bad-webmail.crt · root_ca.pem · intermediate_ca.pem · server.pem · chain.pem · revoked.pem · intermediate.crl (public certs only — no private keys)

1 · Assess the bad certificate 🟢 Easy

Inspect bad-webmail.crt — would a browser trust it? Name every flaw (there are 4).

💡 starter command 
openssl x509 -in bad-webmail.crt -noout -text
openssl x509 -in bad-webmail.crt -noout -subject -issuer -dates -ext subjectAltName

2 · Validate the chain 🟡 Medium

Prove server.pem chains to the root through the intermediate — see it fail without the intermediate first, then make -show_chain print the path it built (that path is the justification, not just OK).

💡 starter command 
openssl verify server.pem                                                                          # FAILS: error 20 (no issuer)
openssl verify -CAfile root_ca.pem server.pem                                                      # STILL FAILS: root didn't sign the leaf
openssl verify -verbose -show_chain -CAfile root_ca.pem -untrusted intermediate_ca.pem server.pem  # OK + prints the chain
# Chain: depth=0 portal.labkit.local (untrusted) ← depth=1 LabKit Issuing CA (untrusted) ← depth=2 LabKit Root CA (anchor)

3 · Check revocation 🟠 Hard

Which serial does intermediate.crl revoke? Is server.pem among them? Re-validate with the CRL enforced.

💡 starter command 
openssl crl -in intermediate.crl -noout -text | grep -A1 'Serial Number'
openssl x509 -in server.pem -noout -serial ; openssl x509 -in revoked.pem -noout -serial
openssl verify -crl_check -CAfile <(cat root_ca.pem intermediate_ca.pem) -CRLfile intermediate.crl server.pem

4 · Constraints, fingerprint, hostname 🔴 Expert

Read the intermediate's CA constraints (why can't it mint a sub-CA?); fingerprint the leaf; and decide whether bad-webmail.crt is valid for the hostname portal.lab.local.

💡 starter command 
openssl x509 -in intermediate_ca.pem -noout -ext basicConstraints,keyUsage
openssl x509 -in server.pem -noout -fingerprint -sha256
openssl x509 -in bad-webmail.crt -noout -ext subjectAltName   # does a wildcard cover the bare domain?
